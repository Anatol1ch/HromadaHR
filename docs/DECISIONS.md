## Межа наступних рішень

На етапі 2.1 обрано мінімальні спільні контракти без RPC-фреймворку, Zod для runtime-валідації в Main та дискримінований результат без витоку текстів винятків. Sandboxed preload збирається наявним Vite в один CommonJS-файл. Авторизація майбутніх захищених операцій має перевірятися в Main перед виконанням; permissive-заглушки немає.

Для майбутніх завдань потрібне окреме погодження бібліотеки SQLite, схеми таблиць, міграцій, механізму й параметрів хешування, політики паролів, формату та порядку створення/відновлення резервних копій, а також наступних IPC-контрактів. Цей документ не визначає їх наперед.

Реалізація наступних функцій, інсталятора, оновлень або релізів потребує окремого завдання. IPC-основа підготовлена до етапу 2.2 SQLite; його реалізація не розпочата.
