# Структурований реєстр · 4.9.3

Знімки зроблено у зібраному Electron зі справжніми Main і preload, синтетичними працівниками та ізольованою SQLite. Тестові дані містять п’ять підрозділів, шість посад, обидва типи працівників, спільні посади й порожній підрозділ.

| [01](01-structure.png) | Одна структурована таблиця з групами |
| [02](02-list.png) | Загальний список із сортуванням за датою |
| [03](03-filtered.png) | Пошук і комбіновані фільтри з перерахованою групою |
| [04](04-reordered.png) | Порядок підрозділів і посад після перестановки в довідниках |
| [05](05-structure-150.png) | Масштаб Electron 150% |
| [06](06-narrow-200.png) | Вузьке вікно при 200% із локальною прокруткою таблиці |

У GUI перевірено зміну режиму, пошук і фільтри, повторне читання черговості, відмову читання довідника та успішну повторну спробу. Загальний список залишався доступним при помилці довідника. Створення додало групу, редагування перенесло рядок і повернуло фокус до кнопки цього працівника, а видалення останнього працівника прибрало його групу. Вузьку геометрію перевірено при масштабі Electron 125%, 150% і 200%.

Пройшли typecheck, build, diff check і дев’ять цільових тестів. Системний DPI Windows, оголошення груп екранним читачем і ручний клавіатурний прохід залишаються для приймання. У вузькому вікні до крайніх колонок можна прокрутити саму таблицю.
