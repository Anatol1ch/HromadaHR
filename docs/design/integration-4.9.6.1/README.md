# 4.9.6.1 – Інтерактивні картки в Electron

Перевірено в робочому Electron на ізольованій SQLite з синтетичними працівниками. Перевірено всі шість переходів з особової картки та всі шість переходів із загального обліку. Кліки виконано по площі картки поза стрілкою. Перевірено Tab, видимий фокус, Enter, Space, підняття картки, зсув стрілки та відсутність обох переміщень при prefers-reduced-motion.

За відсутності права без записів лишаються заголовок, рік, статус і дві дії. При наявності активних і скасованих записів показники та перелік зберігаються. Програмний масштаб Electron перевірено при 100%, 150% і 200%. Системний DPI Windows окремо не перевірявся.
