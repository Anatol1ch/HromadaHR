# 4.9.4 – Вибір працівника в Electron

Ізольована SQLite, 27 синтетичних працівників, зокрема два з однаковими ПІБ та кадрові назви до 200 символів.

- [Початковий стан](01-empty.png)
- [Випливний список при 100%](02-options-100.png)
- [Пошук при 150%](03-search-150.png)
- [Вибраний працівник у правах при 150%](04-selected-150.png)
- [Вузьке вікно при 200%, список відкривається догори](05-narrow-200.png)

У реальному Electron перевірено висоту сторінки до й після відкриття, локальну прокрутку, межі вікна, пошук, Enter, Space, стрілки, Escape, Tab, Shift+Tab, клік поза списком і повернення фокусу після вибору та Escape. Перевірено повторне читання після помилки довідника, відмову від зміни працівника зі збереженням чернетки прав, перехід між вкладками та захист від запізнілої відповіді прав попереднього працівника.

Масштаб змінювався в Electron. Системний DPI Windows окремо не перевірявся.
