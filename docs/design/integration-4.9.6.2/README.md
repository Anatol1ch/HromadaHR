# 4.9.6.2 – Картки й подієва деталізація в Electron

Перевірено на ізольованій SQLite із синтетичними працівниками при масштабі Electron 100%, 150% і 200%. Для обох оглядів перевірено переходи за всіма шістьма видами, вертикальний центр стрілок, довгі назви, відсутність накладання на показник, клавіатурний фокус, Enter, Space і зменшений рух. Підтверджений залишок, нуль, невнесений, неповний та історичний облік відображаються окремо.

Перевірено порожні роки з підтвердженим та відсутнім правом, активний і скасований записи без поточного права, дії прав і журналу. Системний DPI Windows окремо не перевірявся.
