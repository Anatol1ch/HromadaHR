Перестановку виконано перетягуванням у Chromium і клавішами Alt + ↑ / ↓. Після конфлікту ревізії завантажився чинний порядок. Пройшли typecheck, build, diff check, 25 цільових тестів, повний прогін 183 тестів і Electron storage smoke.
