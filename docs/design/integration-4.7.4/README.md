## Що перевірено

- Нова відпустка на шість днів відкрилася з двома нулями. FIFO запропонував два дні зі старого періоду. Підтверджений наступний період, який починався під час відпустки, дав ще чотири дні для ручного списання. Застосування FIFO до введеного розподілу відкрило підтвердження заміни.
- Частковий і надмірний розподіли не відкрили підтвердження збереження. Після зміни діапазону значення за тимчасово недоступним періодом виключалося з підсумку й відновлювалося після повернення допустимої дати. Розподіл 2 + 4 збережено й звірено через IPC. Повторне відкриття показало фактичні списання.
- Непідтверджений наступний період після завершення відпустки відобразився інформаційно й без поля списання. «Підтвердити дні» відкрила штатний редактор після підтвердження закриття чернетки. «Перейти до залишків» з нової форми та з редагування зберігала працівника й вид. Скасування переходу залишило форму відкритою.
- Річна історія при «Права немає» зберегла активні та скасовані записи. Порожній рік показав компактний стан права без ліміту, повторного надання та порожньої таблиці. Перевірено помилку дати до 01.01.2027 після вилучення постійного підпису.
- На 150% та 200% масштабу Electron футер залишився в межах вікна й основна область не отримала загальної горизонтальної прокрутки. Системний DPI Windows, повний обхід клавіатурою та фокус після підтверджень залишаються для ручної перевірки.

Пройшли `pnpm typecheck`, `pnpm build`, `git diff --check`, 27 цільових тестів і фінальний `pnpm test` із 170 тестами та вбудованим Electron storage smoke.
