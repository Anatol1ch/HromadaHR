# 4.9.6.4 – Перевірка в Electron

Ізольована SQLite та синтетичний працівник із довгими назвами посади й підрозділу. Перевірено рівну висоту всіх шести карток і центр стрілок, компактний порожній рік без поточного права, підтверджене право й історію надань. У загальному обліку й подієвих деталях рік має доступну назву без видимого підпису. У журналі обидва статуси відображаються в один рядок, а у вузькому вікні при 200% прокручується таблиця.

- [Шість карток однакової висоти при 100%](01-card-equal-100.png)
- [Порожній подієвий рік без права при 100%](02-no-right-empty-100.png)
- [Підтверджене право й історія при 150%](03-confirmed-history-150.png)
- [Подієва деталізація у вузькому вікні при 200%](04-narrow-event-200.png)
- [Статуси журналу й довгі кадрові назви при 100%](05-journal-status-100.png)
