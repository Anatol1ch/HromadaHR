Робочу область порівняно з [періодним](../screenshots/05-balances.png), [річним](../screenshots/06-annual.png) та адаптивними еталонами [08](../screenshots/08-balances-narrow.png), [09](../screenshots/09-annual-empty-200.png), [16](../screenshots/16-annual-narrow.png), [17](../screenshots/17-balances-125.png). Реальна оболонка, спільні контроли, групування періодів і статуси прав додають контекст до композиції прототипу. На 200% для перегляду зведення використовується вертикальна прокрутка. Загальної горизонтальної прокрутки в перевірених конфігураціях не було. У вузькому сценарії ширина контейнера таблиці становила 431 px, а її вміст прокручувався до 560 px.

У Electron перевірено перемикання шести видів і працівників, збереження працівника між вкладками, активацію пункту клавішею Space, фокус компактного вибору й повернення фокусу з редактора. Через реальний IPC перевірено виправлення історичного залишку, застереження перед новим підтвердженням, вилучення та оновлення зведення. Escape у зміненому редакторі відкриває діалог про незбережені зміни.

Пройшли `pnpm typecheck`, `pnpm build`, `git diff --check` і 43 профільні тести навігації, представлення, річного використання, періодів, прав, IPC та діалогів.

## Відкрите ручне приймання Windows

- Системний DPI 125%, 150% і 200% на реальних моніторах.
- Повний прохід Tab і Shift+Tab, навігація стрілками у відкритому нативному виборі, підказка та меню року.
- Фокус після закриття кожного діалогу, поєднання вузького вікна із системним DPI та прокручування таблиць мишею й клавіатурою.
