# Підтвердження відпустки · 4.9.1

Знімки зроблено в зібраному Electron зі справжніми Main, preload, React та ізольованою SQLite. Працівник, документи й відпустки синтетичні. 150% і 200% позначають масштаб Electron.

У GUI перевірено звичайне й вузьке вікна, Tab, Shift+Tab, Enter, Escape, повернення фокусу, незмінні поля після повернення, повторне відкриття зі зміненим розподілом і доступність футера при прокручуванні. Подвійне натискання надіслало один запис. При втраті відповіді повтор використав той самий request ID, а SQLite зберегла один запис. Конфлікт ревізії залишив форму доступною та зберіг актуальний запис. Вилучення періоду між переглядом і натисканням основної дії зупинило відправлення реєстрації.

Пройшли typecheck, build, diff check і 28 цільових тестів. Системний DPI Windows, екранний читач і ручний клавіатурний прохід на різних розмірах вікна залишаються для приймання.
