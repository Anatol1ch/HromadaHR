# 4.9.5 – Єдиний облік відпусток у Electron

Перевірено з ізольованою SQLite та синтетичними працівниками. В огляді перевірено шість видів, підтверджене й неперевірене право, відсутність права, історичний нуль, неповний облік і відсутність підтверджень. Відкрито всі шість деталей. Для навчальної відпустки звірено два роки початку, для спеціальної – активний і скасований записи та облікову межу. Для спеціального виду без поточного права й без історії перевірено компактний стан.

Перехід із деталей відкрив журнал з фільтрами працівника, виду й року початку. Скасування через журнал оновило річний підсумок, залишивши запис в історії. Перехід до прав зберіг працівника. При помилці читання залишків річні показники лишилися доступними, повторна спроба відновила залишки. Запізніла відповідь попереднього працівника не змінила новий огляд. Перевірено очищення контекстних фільтрів, вибір року стрілками й Enter, повернення фокусу до поля року, перенесення фокусу з картки до деталей і відсутність загального горизонтального переповнення у вузькому вікні при 200%.
