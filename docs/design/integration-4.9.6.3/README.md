# 4.9.6.3 – Перевірка в Electron

На ізольованій SQLite перевірено заголовки таблиці, активний і скасований записи, обмеження п’ятьма останніми наданнями та сортування за спаданням дати початку. У вузькому вікні при 200% таблиця прокручується локально. Для порожнього року залишаються статус і дії без додаткового повідомлення. Перевірено рівну висоту карток у кожній парі, повні назви, центр стрілок і рівномірні шість рядків прав.

- [Огляд при 100%](01-balanced-cards-100.png)
- [Таблиця останніх надань при 100%](02-history-table-100.png)
- [Рядки прав при 150%](03-rights-150.png)
- [Порожній рік у вузькому вікні при 200%](04-empty-year-200.png)

Системний DPI Windows окремо не перевірявся.
