## Поведінка

- **Право підтверджено.** Підтверджені періоди відображаються разом із пропозиціями. За відсутніх даних показано «Залишки ще не внесено» та дію внесення.
- **Не перевірено.** Показано нейтральний статус. Історичні дані, стандартне внесення й чинні облікові перевірки доступні.
- **Права немає.** Показано компактне повідомлення та перехід до прав того самого працівника. У таблиці залишаються підтверджені періоди. Доступні їх виправлення та вилучення за чинними обліковими перевірками. Історичний редактор також приймає документований початковий залишок за період, що почався до 01.01.2027. Додавання запису на обліковій основі нового підтвердженого права потребує спочатку перевірити статус. Виправлення вже підтвердженого запису з такою основою дозволене. Це розмежування діє в редакторі та спирається на чинні облікові основи.
- **Помилка завантаження.** Показано помилку й дію повтору. Підтвердження нового права очікує успішного отримання статусу.

## Перевірки

Пройшли `pnpm typecheck`, `pnpm build`, `git diff --check`, 20 профільних тестів і контрольний `pnpm test` із 169 тестами та вбудованим Electron storage smoke.

У кадровій формі перевірено порожнє збереження з фокусом на першому помилковому полі, створення працівника, обидва вкладені діалоги довідників, фокус після додавання запису, Tab і Shift+Tab на межах форми, Escape та продовження редагування. Через IPC перевірено збережену зміну й довжину кадрових реквізитів. Виявлені проблеми з фокусом виправлено. Довгі слова в обраних значеннях і варіантах Select тепер переносяться. У числових блоках і таблицях залишено чинну композицію.

В Electron звірено історичний нуль, виправлення, вилучення й відхилення нового підтвердження. Помилку читання прав відтворено тимчасовою відповіддю IPC в тестовому процесі, після чого відновлено справжній обробник і виконано повтор.

Системний DPI Windows залишається для ручної перевірки. Потрібно пройти кадрові форми та вкладені довідники на робочому моніторі при 125%, 150% і 200%, перевірити повний обхід клавіатурою та фокус після закриття діалогів. Візуальні знімки використовують браузерне масштабування Electron.
