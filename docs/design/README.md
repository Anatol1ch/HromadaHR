# Прототип модуля «Відпустки»

Відкрийте [index.html](index.html) у Chromium, Edge або Firefox з локальної теки. Сервер і підключення до мережі не потрібні. Поле «Екран» перемикає сім екранів, а «Приклад» змінює їхні демонстраційні стани. У робочій області можна вибрати всі шість видів відпусток. Кнопки без сценарію показують пояснення про призначення прототипу. Усі дані синтетичні, зміни діють лише до перезавантаження сторінки.

Головна пропозиція – перенести дворівневу композицію «Загальної інформації» на залишки, огляд працівника та діалоги. Залишки показують навігацію видів поряд із робочими даними. Журнал і права дають контекст для порівняння зі схваленими екранами. Опис патернів і перелік файлів наступного підетапу наведено в [дизайн-стандарті](HROMADAHR-DESIGN-SYSTEM.md).

## Фактичний перегляд

Прототип відкрито через `file://` у Chromium, який входить до локального Electron. Знімки отримано через `capturePage()`. Перевірено 17 прикладів у шести конфігураціях. Базові розміри області – 1440×980, 660×900 і 390×844. Масштаб 125%, 150% і 200% застосовано через `setZoomFactor` у вікні 1440×980. В усіх 102 комбінаціях перевірено ширину документа і видимість футера для діалогів. Це браузерний масштаб. Приймання робочого застосунку з масштабом Windows залишається окремим сценарієм.

Виявлене переповнення футера при 200% усунено розподілом доступної висоти між панеллю прикладів, шапкою, прокручуваним вмістом і футером. Вузький список видів замінено групованим вибором, щоб дані були ближче до початку екрана.
