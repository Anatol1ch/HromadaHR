# HromadaHR

Локальний настільний застосунок кадрового обліку для органів місцевого самоврядування України. Версія **0.1.0**. Цільова платформа – Windows 10 і Windows 11, пілотний обсяг – близько 30 працівників.

## Реалізовані модулі

- **Працівники.** Реєстр із групуванням за підрозділами й черговістю посад, пошуком, фільтрами та підсумками вибірки. Створення, редагування й захищене видалення кадрових записів. Особова картка з переходами до обліку та прав.
- **Довідники.** Незалежні довідники підрозділів і посад зі створенням, перейменуванням, безпечним видаленням та ручною черговістю, що зберігається в SQLite.
- **Відпустки.** Шість видів, поточні права, підтверджені періоди й залишки для трьох накопичуваних видів та річні фактичні надання для трьох подієвих. Журнал і історія, підтвердження реєстрації, редагування з перевіркою ревізії та скасування з поверненням списаних днів. Розподіл ручний, FIFO застосовується за явною дією. Контекстні переходи до залишків та історії зберігають чернетку.
- **Резервування.** Один перевірений знімок у двох налаштованих місцях, каталог і захищене відновлення з перевіркою джерела та можливістю повернути попередній стан.

«Стаж і ранги» та «Документи» поки представлені заглушками. Наступний запланований напрям – «Стаж і ранги» за окремим завданням. Інсталятор та автоматичні оновлення не реалізовані. Технічна перевірка не є прийманням до експлуатації.

## Архітектура

Electron, React, TypeScript і Vite. SQLite v12 працює в Main через better-sqlite3 з WAL, зовнішніми ключами, версійними міграціями й перевіркою checksum. Renderer працює в sandbox із context isolation, без прямого доступу до Node.js або БД. Взаємодія з Main проходить через типізований IPC, дозволений preload та перевірку аргументів і відправника. Built працює локально без сервера. Користувацькі дати відображаються як ДД.ММ.РРРР.

Міграція v5 разово очищує погоджені тестові кадрові записи після захисної копії та зберігає довідники. Відновлення v4 або старішої копії також проходить через v5. Для повернення актуальних працівників використовуйте копію v5 або новішу.

## Встановлення, запуск і перевірки

Потрібні Node.js 24.22.1 і pnpm 11.25.0. Перше встановлення залежностей та Electron потребує інтернету.

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Dev використовує `http://127.0.0.1:5176/`. Після змін Main або preload перезапустіть dev-сеанс.

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm start:built
```

`pnpm test` включає Electron storage smoke. `start:built` запускає наявну збірку без Vite. Dev і built використовують незалежні профілі та БД. Для перевірок міграцій і відновлення використовуйте ізольований тестовий профіль.
